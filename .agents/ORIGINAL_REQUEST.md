# Original User Request

## Initial Request — 2026-09-01T21:06:02Z

Разработать с нуля AI-систему наведения турели-перехватчика дронов с сеткомётом. Система должна обнаруживать дрон с веб-камеры, предсказывать его будущее положение (Калман-фильтр), рассчитывать баллистическую траекторию сетки с учётом физики, и наводить турель в точку упреждения для перехвата. Назначение — боевое / полевое применение против вражеских БПЛА (скорость до 150-200 км/ч). Этап — программный MVP с симуляцией (железо подключается позже).

Working directory: ~/teamwork_projects/drone_turret_v2
Integrity mode: demo

## Контекст

- Существующий прототип (v1) лежит в ~/teamwork_projects/drone_ai_detector/
- Файлы моделей YOLO: yolov8n.pt (стандартная) и drone_best.pt (дроны) — скопировать из v1
- У пользователя есть Arduino Uno
- Камера: пока 480p, планируется апгрейд до 1080p
- Планируется LiDAR (TFMini/TF-Luna) для измерения расстояния
- Сеткомёт: пневматический, дальность ~50 метров (будет разработан позже)
- OS: Windows

## Requirements

### R1. Детекция и трекинг дронов в реальном времени
Система должна захватывать видеопоток с веб-камеры, обнаруживать дроны с помощью YOLOv8, и устойчиво сопровождать одну выбранную цель с помощью ByteTrack. В GUI должно быть переключение между стандартной моделью (yolov8n.pt) и моделью для дронов (drone_best.pt).

### R2. Предиктивный трекинг (Калман-фильтр)
Реализовать фильтр Калмана для предсказания будущего положения дрона. Система должна:
- Оценивать текущую позицию, скорость и ускорение дрона в пиксельных координатах
- Предсказывать положение дрона через заданный временной интервал (0.1 - 2.0 сек)
- Продолжать предсказывать траекторию даже если YOLO потерял дрон на несколько кадров
- Визуализировать предсказанную траекторию на экране (пунктирная линия вперёд)
- Рассчитывать и отображать скорость дрона (км/ч, пересчёт через известный размер дрона или расстояние)

Key implementation: use cv2.KalmanFilter with state vector [x, y, dx, dy, ddx, ddy] (6 states) for position+velocity+acceleration. Transition matrix must account for dt between frames.

### R3. Баллистический калькулятор (сеткомёт)
Реализовать модуль расчёта траектории сетки-снаряда. Учитываемые параметры:
- Начальная скорость снаряда (настраиваемая, по умолчанию ~80 м/с для пневматики)
- Масса снаряда + сетки (настраиваемая)
- Гравитация (9.81 м/с^2)
- Аэродинамическое сопротивление: d(v_p)/dt = -(1/2m) * rho * Cd * A(t) * |v_p| * v_p + g
- Cd = 1.1-1.5 (variable as net expands)
- Use 4th-order Runge-Kutta numerical integration for projectile trajectory
- Newton-Raphson root-finding for intercept point
- Distance to target (from LiDAR or bbox estimation)
- Speed and direction of target (from Kalman filter)

Output: lead point — where to aim so net and drone meet simultaneously. Visualize this point on screen with a separate marker (intercept crosshair).

Key numbers: At 50m range with 60 m/s muzzle velocity (~1s flight), drone at 200 km/h moves ~56m. Gravity drop at 50m: ~0.34m.

### R4. Измерение расстояния до дрона
Два режима:
- LiDAR: Чтение данных с TFMini/TF-Luna через Serial (когда подключён)
- Оценка по bbox: Приблизительный расчёт дистанции по размеру bounding box (когда LiDAR не подключён). Use formula: distance = (known_drone_size * focal_length) / bbox_size_pixels

### R5. PID-управление серво-моторами через Arduino
PID-контроллер для наведения двух серво-моторов (pan/tilt). Турель должна целиться не в текущее положение дрона, а в точку упреждения (lead point из R3). Режим симуляции без Arduino обязателен. Send absolute angles (0-180) via Serial.

### R6. Web-интерфейс управления
Веб-приложение (Python FastAPI backend + HTML/JS frontend). Через интерфейс:
- Выбор камеры, модели нейросети, класса цели
- Настройка чувствительности (confidence threshold)
- Настройка параметров сеткомёта (скорость снаряда, масса, Cd)
- Подключение/отключение Arduino и LiDAR
- На видеопотоке: прицел, рамка цели, предсказанная траектория (пунктир), точка упреждения (отдельный маркер), FPS, расстояние, скорость дрона (км/ч), статус залочки

### R7. Модульная архитектура и документация
Код разбит на логические модули (минимум 5 файлов). README.md с инструкцией по установке и запуску. requirements.txt с зависимостями. Arduino firmware (.ino file) included.
