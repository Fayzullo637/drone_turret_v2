# Drone Turret V2 (Киберфизическая система перехвата)

Данный проект представляет собой программно-аппаратный комплекс для обнаружения, сопровождения и расчета баллистического перехвата маневрирующих БПЛА (дронов). Система построена на модульной, высокопроизводительной конвейерной архитектуре, объединяющей нейросетевое зрение, стохастическую фильтрацию и численное моделирование физики.

## 1. Архитектура системы

Пайплайн обработки данных работает в реальном времени и строго разделен на независимые подсистемы:

1. **Захват и Детекция:** Видеопоток анализируется нейросетью **YOLOv8**.
2. **Ассоциация и Трекинг:** Алгоритм **ByteTrack** связывает обнаружения между кадрами в единую траекторию.
3. **Кинематическая Фильтрация:** **6-мерный фильтр Калмана** сглаживает шум и рассчитывает вектор состояния цели (скорость и ускорение).
4. **Дальнометрия:** Дистанция измеряется аппаратно (**LiDAR**) или оценивается оптически по размеру Bounding Box.
5. **Баллистика:** Численный вычислитель (**RK4** + алгоритм Ньютона-Рафсона) решает задачу упреждения.
6. **Управление:** **ПИД-регулятор** конвертирует координаты в команды для сервоприводов (Pan/Tilt) по Serial-шине.

## 2. Ключевые механизмы и алгоритмы

### 2.1. Оптический трекинг и локализация
Основой обнаружения является оптимизированная модель **YOLOv8**. Для сохранения идентичности цели (Track ID) применяется **ByteTrack**, позволяющий системе удерживать "захват" на конкретном объекте даже при пересечении траекторий нескольких дронов. Реализован механизм *Model Hot-Swapping* — бесшовная горячая замена весов нейросети (например, с `yolov8n.pt` на кастомную `drone_best.pt`) без прерывания видеопотока.

### 2.2. Предиктивная кинематика (6-State Kalman Filter)
Поскольку оптические измерения зашумлены, применяется расширенный линейный фильтр Калмана. 
Вектор состояния размерностью 6 имеет вид: `X = [x, y, vx, vy, ax, ay]ᵀ` (позиция, скорость, ускорение).
* **Динамический временной шаг (dt):** Матрица перехода состояний `F(dt)` пересчитывается для каждого кадра, компенсируя нестабильность частоты кадров (FPS jitter).
* **Коастинг (Coasting):** При визуальном перекрытии цели (до 10+ кадров) система не теряет захват, а переходит в режим слепого экстраполирования (pure prediction), вычисляя ожидаемую позицию на основе накопленного ускорения.

### 2.3. Численный баллистический вычислитель
Вместо упрощенной параболической аппроксимации, для расчета точки встречи со снарядом (сеткометом) применяются методы численной физики.
* **Интегратор Рунге-Кутты 4-го порядка (RK4):** Выполняет дифференциальное интегрирование движения снаряда в трехмерном пространстве с учетом гравитации и аэродинамического сопротивления. Модель учитывает динамически изменяющуюся площадь миделя $A(t)$ (раскрывающаяся в полете сетка):  
  $$ \frac{d\vec{v}}{dt} = -\frac{1}{2m} \rho C_d A(t) |\vec{v}|\vec{v} + \vec{g} $$
* **Метод Ньютона-Рафсона:** Применяется как итеративный алгоритм поиска корней для нахождения точного времени перехвата $t_{int}$. На выходе формируются прецизионные углы азимута (Pan) и элевации (Tilt) для упреждающего огня.

### 2.4. Гибридная дальнометрия (Sensor Fusion)
Система поддерживает дублированную систему оценки дистанции (Z-координаты):
1. **Аппаратная:** Обработка 9-байтных бинарных пакетов лазерного дальномера (TFMini/TF-Luna) с валидацией контрольных сумм на лету.
2. **Программная:** При отказе LiDAR включается резервная пинхол-модель: $Distance = (TargetSize \times FocalLength) / BBoxWidth$.

### 2.5. Дискретный ПИД-регулятор
Для трансляции расчетных углов в механическое движение сервоприводов реализован специализированный ПИД-регулятор:
* **Anti-Windup:** Динамическое ограничение (clamping) интегральной составляющей, предотвращающее перекомпенсацию при выходе за механические лимиты турели (0–180°).
* **Deadband Filter (Мертвая зона):** Подавление высокочастотного дребезга (jitter) сервомоторов при удержании прицела на неподвижной или медленной цели.

## 3. Программная инфраструктура и интерфейсы

* **Backend-ядро:** Разработано на Python, использует асинхронный фреймворк `FastAPI` для маршрутизации REST API.
* **Тактический Web HUD:** Одностраничное фронтенд-приложение (HTML/JS/CSS). Обеспечивает трансляцию MJPEG-потока с нулевой задержкой и наложением OSD-телеметрии (вектор цели, перекрестие упреждения, дистанция, скорость в км/ч, статус замка).
* **Hardware Firmware:** Микроконтроллер Arduino Uno (`firmware/drone_turret_firmware.ino`). Реализует неблокирующий конечный автомат для обработки команд Serial-шины, генерации ШИМ-сигналов и контроля аппаратного сторожевого таймера (Watchdog).

## 4. Развертывание и запуск

Проект покрыт пятиуровневой системой автоматизированного тестирования (Tier 1..5), включающей физические бенчмарки и виртуальные заглушки для Serial-портов.

```bash
# 1. Установка production-зависимостей
pip install -r requirements.txt

# 2. Прошивка Arduino
# Загрузите код из директории firmware/drone_turret_firmware.ino в плату

# 3. Инициализация конвейера и запуск веб-сервера
python main.py
```

После запуска системы, тактический интерфейс управления доступен в браузере по адресу `http://localhost:8000`.
