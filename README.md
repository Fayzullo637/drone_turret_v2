# Drone Turret V2 (AI Interceptor Turret)

Модульная, высокопроизводительная киберфизическая система наведения для антидроновой турели.

## Архитектура проекта

Проект построен на базе конвейерной архитектуры, где каждый модуль выполняет свою задачу в реальном времени:

1. **Компьютерное зрение (Vision)**: Захват видеопотока и детекция дронов с помощью **YOLOv8**, с последующим трекингом через **ByteTrack** для сохранения идентификатора цели.
2. **Кинематика и Трекинг (Tracking)**: Использование **6-мерного фильтра Калмана** для сглаживания траектории, прогнозирования движения и удержания цели даже при кратковременном перекрытии обзора (до 10 кадров).
3. **Баллистика (Ballistics)**: Вычисление точки упреждения. Используется численный интегратор **Рунг-Кутты 4-го порядка (RK4)** для расчета траектории снаряда (сетки) с учетом гравитации и аэродинамического сопротивления, а также метод Ньютона-Рафсона для точного нахождения точки перехвата.
4. **Сенсоры и Дистанция (Sensors)**: Определение дистанции до цели через бинарный парсер для LiDAR (TFMini/TF-Luna), либо через резервную оптическую оценку по размеру bounding box'а.
5. **Управление (Control & Comms)**: ПИД-регулятор (PID) конвертирует координаты перехвата в команды для сервоприводов [Pan/Tilt], которые отправляются на микроконтроллер Arduino по Serial-порту.
6. **Web HUD (FastAPI)**: REST API и тактический веб-интерфейс с живым MJPEG-потоком, наложением прицела (reticle), траектории и телеметрии в реальном времени.

## Структура репозитория

- `drone_turret/` — основной Python пакет (зрение, баллистика, ПИД-регуляторы).
- `firmware/` — прошивка для Arduino (`.ino`) для управления сервоприводами и стрельбой.
- `models/` — веса нейросетей YOLO.
- `static/` — frontend-часть (HTML, JS, CSS) для тактического HUD.
- `tests/` — комплексная система E2E и unit-тестов.
